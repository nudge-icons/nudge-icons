# @nudge-icons/svg

## 0.3.0

### Minor Changes

- 81fcdc5: 50 new interface icons: arrows and chevrons (`ArrowUpCircle`, `ArrowUpLeft`, `ArrowLeftRight`, `ChevronsUp`, and more), states and signs (`XCircle`, `PlusCircle`, `MinusCircle`, `HelpCircle`, `AlertCircle`, `Ban`, `ShieldAlert`, `EyeOff`, `BellOff`, `MapPinOff`), controls (`Funnel`, `FunnelX`, `SortAscending`, `SortDescending`, `Ellipsis`, `GripVertical`, `Move`, `Expand`, `Shrink`, `ToggleLeft`, `ToggleRight`, `MousePointer`, `Hand`), shapes (`Square`, `CheckSquare`, `Triangle`, `Diamond`, `Hexagon`) and `CloudUpload`, `CloudDownload`, `TrendingUp`, `TrendingDown`, `HeartPlus`, `HeartMinus`, `Crosshair`, `AppWindow`. `ToggleLeft` switches on with `active`. New filled variants: `XCircleFilled`, `PlusCircleFilled`, `MinusCircleFilled`, `CheckSquareFilled`, `AlertCircleFilled`, `SquareFilled`, `TriangleFilled`, `DiamondFilled`, `HexagonFilled`.
- 2ccf724: 52 new icons for text, documents and files: editing (`Undo`, `Redo`, `FloppyDisk`, `Pen`, `Highlighter`, `Eraser`, `Signature`, `LinkBreak`), text formatting (`Bold`, `Italic`, `Underline`, `Strikethrough`, `Subscript`, `Superscript`, `Heading`, `Type`, `Quote`, `ListNumbers`, `TextAlignLeft`, `TextAlignCenter`, `TextAlignRight`, `CursorText`, `TextWrap`, `Columns`), files and folders (`FileText`, `FilePlus`, `FileMinus`, `FileX`, `FileCode`, `FileLock`, `FileSearch`, `FileImage`, `FileVideo`, `FileSpreadsheet`, `FileArchive`, `FolderPlus`, `FolderMinus`, `FolderCheck`, `FolderLock`, `FolderSearch`, `Folders`) and `Book`, `Notebook`, `StickyNote`, `Scroll`, `BookmarkPlus`, `BookmarkCheck`, `Presentation`, `Ticket`, `Certificate`, `Asterisk`, `Copyright`.

### Patch Changes

- cc7a3ab: `Paperclip` is drawn narrower, with smaller loops and gaps between the wires.

## 0.2.0

### Minor Changes

- 50 new icons, most of them for AI interfaces: assistant and chat (`ChatBot`, `ChatSparkle`, `ChatTyping`, `Prompt`, `Stop`, `ThumbsUp`, `ThumbsDown`), models and agents (`Robot`, `Brain`, `Cpu`, `Network`, `Workflow`, `Automation`), voice (`Microphone`, `Waveform`, `Volume`, `Headphones`), scanning (`Scan`, `ScanEye`, `ScanText`, `ScanFace`) and generation (`ImageSparkle`, `FileSparkle`, `CodeSparkle`, `SearchSparkle`, `Translate`, and more). `Microphone`, `Volume` and `Headphones` cross out with `active`; `Stop` turns into a play triangle. New filled variants: `ThumbsUpFilled`, `ThumbsDownFilled`, `LightbulbFilled`. Icon metadata has an optional `themes` field (`["ai"]`).

## 0.1.0

### Minor Changes

- 15d9fcb: First release: animated line icons for React and Vue from one source, with CSS-only motion, second states (`active`), filled and half variants, a `/static` entry without motion, and plain SVG files with metadata.
