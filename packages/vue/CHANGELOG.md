# @nudge-icons/vue

## 0.2.0

### Minor Changes

- 50 new icons, most of them for AI interfaces: assistant and chat (`ChatBot`, `ChatSparkle`, `ChatTyping`, `Prompt`, `Stop`, `ThumbsUp`, `ThumbsDown`), models and agents (`Robot`, `Brain`, `Cpu`, `Network`, `Workflow`, `Automation`), voice (`Microphone`, `Waveform`, `Volume`, `Headphones`), scanning (`Scan`, `ScanEye`, `ScanText`, `ScanFace`) and generation (`ImageSparkle`, `FileSparkle`, `CodeSparkle`, `SearchSparkle`, `Translate`, and more). `Microphone`, `Volume` and `Headphones` cross out with `active`; `Stop` turns into a play triangle. New filled variants: `ThumbsUpFilled`, `ThumbsDownFilled`, `LightbulbFilled`. Icon metadata has an optional `themes` field (`["ai"]`).

## 0.1.0

### Minor Changes

- 15d9fcb: First release: animated line icons for React and Vue from one source, with CSS-only motion, second states (`active`), filled and half variants, a `/static` entry without motion, and plain SVG files with metadata.
